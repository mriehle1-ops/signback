# SignBack

Relearn American Sign Language five minutes a day. A phone-first web app: a placement check finds the signs you still know, spaced review brings back the rest right before you'd forget them, and short lessons cover the facial grammar (brows, head shakes, mouth shapes) that ASL runs on.

Open it on a phone and add it to the home screen. Progress stays on the device.
